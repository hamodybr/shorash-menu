# SHORASH Digital Menu v2

نسخة مطورة لمنيو SHORASH:
- تصميم Premium Mobile First
- Hero/Branding
- قسم Featured
- بحث
- أقسام قابلة للتمرير
- عربي / English
- نافذة تفاصيل للصنف
- WhatsApp
- الأسعار قابلة للإضافة لاحقًا من `data.js`
- الصور والأسماء مأخوذة من ملفاتك الأصلية

## إضافة السعر
في `data.js` غيّر:
`"price": ""`
إلى:
`"price": "7,000"`

## إضافة وصف
غيّر:
`"description": ""`
إلى وصف الأكلة.

## نشره
ارفع الملفات إلى GitHub repository ثم فعّل GitHub Pages من Settings → Pages.

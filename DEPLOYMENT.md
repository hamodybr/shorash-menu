# نشر SHORASH Digital Menu

1. أنشئ Repository جديد باسم `shorash-menu`.
2. ارفع كل الملفات إلى الجذر.
3. Settings → Pages → Deploy from a branch → main → / (root).
4. رابط GitHub Pages سيظهر لك.

## الدومين
النسخة مجهزة لـ `menu.shorashrest.com`.
أضف CNAME في DNS:
`menu` → `USERNAME.github.io`

ثم GitHub → Settings → Pages → Custom domain → `menu.shorashrest.com`.
